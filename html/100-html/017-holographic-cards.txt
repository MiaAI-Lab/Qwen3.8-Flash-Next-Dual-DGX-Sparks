TITLE: Arcanum Vault — Holographic Collectible Card Vault

PROMPT: Build a single self-contained page (one HTML file, all CSS in one <style>, all JS in one <script>, no external assets, system fonts only) that presents a premium collectible-card vault called "Arcanum Vault — Series IV · Foil & Guilloché · Edition of 120". Background is #08070b lit by a soft violet top light (radial gradient, blurred), a slow swaying conic light beam, a cyan floor bounce, an overlaid scanline "grain" made of two repeating-linear-gradients at ~3% white in overlay blend, a heavy vignette, and ~46 JS-spawned dust motes (2px dots in #fde68a / #a78bfa / #22d3ee) that drift upward on long randomized linear-loop animations with horizontal drift variables. Masthead: an inline-SVG foil crest (diamond in two rings, gradient stroke) plus the wordmark "Arcanum Vault" set in a Bodoni/Didot stack with a rainbow gradient clipped to text, letterspaced .22em uppercase, subtitle in 0.6rem monospace letterspaced .34em; right side a monospace HUD (Serial / Grade / Tier) that updates with focus.

The centrepiece is a stage (perspective: 1500px, perspective-origin 50% 44%) holding four cards as true 3D objects (each card transform-style: preserve-3d, ratio 1:1.4, width min(66vw,318px)). Cards sit in a fan: focus offset 0 is centred at scale 1, z 0; neighbours translate ±148px, rotateY ∓15deg, translateZ −210px per step, scale −0.085 per step, drop 12px; the fan resolves the shortest way round the ring and collapses to a tight 26px fan under 720px. Neighbours are dimmed by an in-face "veil" overlay (never a CSS filter on a preserve-3d node — that flattens the flip). Inside each card: card → card__tilt (JS-eased pointer rotation) → card__inner (the flip, rotateY 180deg with cubic-bezier(.62,.02,.2,1) over .86s, both faces backface-hidden) → faces.

Front face: foil frame rendered as a border-only ring using conic-gradient + mask padding-box/exclude, spinning slowly via a --spin custom property; a second hairline gold inner rule inset 9px; header row with "№ 001 · Plate I" in 0.5rem monospace and a rarity chip; a 47%-tall art window with a layered gradient ground (violet top-left glow, cyan bottom pool, #120f22 → #08070d body) holding an inline-SVG sigil drawn with a shared foil gradient stroke: a moth (Nyx, the Moth Cardinal), a leviathan arch with wave rules (Vaalmouth, the Ninth Fathom), a clockwork heart with a dashed-stroke gear ring and mainspring spiral (Cor Horologii), and a crow perched on a sword (Corvus on the Meridian Blade); Bodoni/Didot title with tier-tinted gradient text; monospace class line; italic Hoefler/Palatino flavour text; four real stat bars (label, gradient fill violet→cyan→gold animating from 0 width, numeric value); and a micro-print hairline strip at the bottom repeating "arcanum vault · series iv · foil no. …" at 3.6px letterspaced .42em, slowly scrolling.

Holographic layer: two absolutely-positioned overlays above the content, both mix-blend-mode: color-dodge. The main layer stacks a repeating-linear-gradient micro-etch (1px light / 1px dark at a per-card angle --etch) over a conic-gradient rainbow using #a78bfa, #22d3ee, #f472b6, #fde68a and white; its centre follows the pointer via --gx/--gy, its start angle is --spin + --tiltA (the pointer angle), and it is masked by the intersection of a rotating linear-gradient band (--sweep, driven by pointer X) and a radial falloff, so the rainbow only exists in a band that sweeps as the card tilts. A second fine layer adds perpendicular 1-in-7px etch lines at low opacity, and a third "glint" (screen blend) adds the specular streak. Opacity of all three rises with --lift (pointer distance).

Back face: engraved guilloché built from one inline-SVG <symbol> reused with <use> — a rotated fine line pattern, a radial glow, six concentric circles, an 18-ellipse rotated rosette slowly turning (60s), four sine-wave bands and a double border rect — plus a centred crest plate, the letterspaced word "Arcanum", and its own mini holo + foil ring.

Console under the stage: round prev/next arrow buttons, "01 / 04 · Nyx" live label, an "OPEN PACK" pill with a rainbow gradient fill and a hover shine sweep, and a "FLIP" pill. A ledger grid lists print run, 120µm rainbow foil stock, guilloché engraving, Mythic 1:120 / Rare 1:14 odds, 3.6pt micro-print band, live pull counter and last pull. Footer carries the credit line, an italic aphorism and the key hints.

Interaction: pointer position over the page tilts the focused card up to 13deg Y / 10deg X toward the pointer, eased by an rAF lerp (k=0.11), and simultaneously drives every holographic variable; leaving the page eases it back to rest. Arrow keys, Home/End or the arrow buttons cycle focus while neighbours recede and rotate into the fan. Click (or Enter/Space, or F) flips the focused card with a true 3D flip; clicking a neighbour focuses it instead, and a >9px pointer travel cancels the click. "OPEN PACK" (or O) rolls weighted odds (18% Mythic, 40% Rare, 42% Common), deals the chosen card up from below with a back-out overshoot easing plus a shine sweep across the face, fires a full-screen rarity flash tinted to the tier, logs the pull in the ledger and stacks a colour-coded chip in a corner tray. Everything degrades gracefully under prefers-reduced-motion: no dust, no beam, instant easing, no auto-deal. Responsive from 360px (tighter fan, stacked masthead, no tray) to 2560px (352px cards).

DESIGN: The page is a dim auction-house vitrine: near-black #08070b, one soft violet overhead light and drifting dust, so that the only saturated colour in the room comes from the foil itself. Typography pairs a high-contrast Didot/Bodoni display with a wide-tracked monospace for catalogue data and an italic old-style serif for flavour, which reads as "collector's object" rather than "app". Motion is deliberately physical — cards hang in a fan on eased springs, the rainbow is masked to a band that only exists while you move, and the pull is a real deal with overshoot. Rarity is communicated purely through colour temperature (gold Mythic, cyan Rare, cold-grey Common) so the vault stays calm and every Mythic pull feels like an event.

TECHNIQUES:
- transform-style: preserve-3d at three nested levels (card → tilt → inner) so pointer tilt, fan rotation and the 180deg flip compose without flattening
- deliberately avoiding CSS filter/opacity on preserve-3d nodes (they force transform-style: flat); neighbour dimming is done with an in-face veil overlay instead
- border-only conic-gradient foil frame via mask: linear-gradient content-box + mask-composite: exclude (with -webkit-mask-composite: xor)
- holograph = repeating-linear-gradient micro-etch + conic-gradient rainbow under mix-blend-mode: color-dodge, masked by the intersection of a rotating linear band and a radial falloff (mask-composite: intersect)
- engraved guilloché as one inline-SVG <symbol> (pattern + concentric circles + 18 rotated ellipses + sine bands) reused through <use href>
- shared SVG linearGradients (#foil, #blade) used as stroke/fill for all four hand-drawn sigils
- requestAnimationFrame lerp easing for pointer tilt; JS-timed back-out easing curve for the deal overshoot
- CSS custom properties (--gx/--gy/--sweep/--tiltA/--spin/--lift/--etch) as the animation API between JS and CSS
- stat bars animated from 0 via width transition triggered by a data-state attribute appearing
- JS-generated dust field with per-mote CSS variables for drift and opacity
- border-only gradient rings, gradient-clipped display type, letterspaced 3.6px micro-print band, letter-spaced monospace catalogue data
- prefers-reduced-motion branch that disables dust/beam, snaps easing and skips the entry deal

INTERACTION:
- Pointer anywhere sets a target tilt for the focused card (max 13deg Y / 10deg X) that is eased toward at 11% per frame; the same vector drives the hologram centre, sweep angle, rainbow phase and specular lift, so the foil only lives while you move
- ArrowLeft/ArrowRight (and ArrowUp/ArrowDown), Home/End, or the round pager buttons cycle focus; the ring resolves the shortest path so the fan rotates rather than jumps
- Neighbours recede on Z, rotate away into the fan, scale down and dim; their holo layers idle at a fixed angle
- Click the focused card (or F / Enter / Space / the FLIP pill) for a true 3D flip to the guilloché back; clicking a neighbour focuses it; drag-tolerant click detection; ARIA-pressed and aria-live keep the state announced
- OPEN PACK (or O) rolls weighted rarity, deals the winner up from below with overshoot, sweeps a shine across the face, flashes the tier colour full-screen, increments the ledger and drops a tier-coloured chip in the tray
- Resize re-solves the fan (mobile: compact 26px offsets, no side tray); pointerleave/blur ease everything back to rest
